# DMS-Eval: Scope Note & Minimum Viable Submission (MVS)

**Milestone:** M0 — Scope Lock (16 Aug 2026)  
**Target Submission:** CAISAIS — 31 Aug 2026

## 1. Core Research Question & In-Scope Focus
- Strictly **frame-level observable cues** (eyes open/closed, yawning, phone usage, smoking, etc.)
- Evaluation of lightweight object detector architectures on efficiency vs. detection accuracy.

## 2. Minimum Submission Deliverables (What WILL be delivered)
- [ ] **Frozen Dataset Protocol & Manifests:** Documented ontology, leakage-free driver-level splits.
- [ ] **Runnable Evaluation Harness:** CLI to evaluate models with deterministic metrics.
- [ ] **Controlled Experimental Results:** Standardized benchmarking under equal conditions.
- [ ] **Traceable Artifacts:** Logs, profiling summaries, and checkpoint manifests.
- [ ] **Final Manuscript (PDF):** IEEE conference-formatted paper addressing the RQ.

## 3. Explicit Out-of-Scope (What will NOT be delivered)
- Temporal state aggregation (e.g., PERCLOS over time windows / LSTM / Transformer sequence modeling).
- Full commercial embedded deployment / specialized on-chip ASIC quantization beyond standard profiler baselines.
- Real-time video streaming pipeline or in-vehicle hardware integration.
